# S1 — 자라는 아기 AI

v2 §3.1과 우선 규칙 §3.1-b를 구현한다. 행동 CSV의 월령과 신호, 일과 CSV의 수유·깨어 있는 시간·기저귀 범위를 시뮬레이션의 근거로 사용한다.

- `/`는 아기의 표정, 가상 월령, 감정, 돌봄 버튼 5개와 자료 출처를 표시한다.
- `GET /api/baby`는 가상 월령·감정·현재 행동 및 행동 ID를 반환한다. `POST /api/baby/care`에는 `{"action":"feed"}`와 같은 정해진 돌봄 종류만 받는다.
- 돌봄으로 바뀌는 것은 아기 상태다. SQLite에는 가상 아기 상태 한 행만 저장하며 사람이나 돌봄 이력을 기록하지 않는다.
- 1초마다 상태를 갱신한다. 하루 수유·기저귀 횟수 범위의 중간값과 깨어 있는 시간 범위의 중간값을 사용한다. 이는 시뮬레이션 속도 조절용이다.
- 월령마다 유효한 돌봄 10회와 `ceil(28 × 월령 / 12)`일이 필요하다. `BABY_SPEED`가 1보다 크면 데모 모드로 일수 조건을 생략한다.
