# S0 기반 구성

Python 3.11에서 AI 육아 로봇을 개발할 수 있도록 서버 진입점, 로컬 설정, 테스트와 CI를 구성한다.

## 인터페이스

- `python -m app`을 실행하면 기본 주소는 `127.0.0.1:8000`이다.
- `APP_PORT`는 1~65535의 포트만 허용한다. 환경변수, 프로젝트 루트의 `.env`, 기본값 순서로 적용한다. 잘못된 포트는 서버를 시작하기 전에 한국어 오류와 종료 코드 2를 반환한다.
- `GET /health`는 HTTP 200과 JSON `{"status":"ok"}`를 반환한다.

## 합격 기준

- [x] Python 3.11에서 고정된 의존성을 설치하고 장치·모델·API 키 없이 pytest를 실행할 수 있다.
- [x] 실제 서버에서 `/health` 응답을 받고, `HOST` 등의 환경변수나 `.env`로 리스닝 주소를 변경할 수 없다.
- [x] 설정의 우선순위와 포트 검증을 테스트한다.
- [x] `AGENTS.md`에 개인정보·안전 원칙 15개를 포함하고 로컬 설정과 데이터·모델 디렉터리를 Git에서 제외한다.
- [x] Linux와 Windows의 Python 3.11에서 pytest를 실행하는 GitHub Actions를 구성한다.

GitHub Actions의 원격 실행 결과는 PR에서 확인한다. 하드웨어 기능은 후속 단계에서 도입한다.
